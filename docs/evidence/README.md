# Prototype development evidence

These screenshots record distinct chronological development stages. Assessment responses shown in later stages belong to the **Ujian prototaip** QA session, not school students. They must not be described as classroom implementation or evidence that learning outcomes improved.

1. [Original village before learning integration](01-village-before-learning.jpg): exploration environment and the earlier fish-collection objective.
2. [Learning stations and mission book](02-learning-stations.jpg): the new lesson structure, progress indicators and original visual materials.
3. [Question interaction and feedback](03-question-feedback.jpg): a correct response after a deliberate incorrect attempt, with a hint and explanatory feedback. The question wording was subsequently refined to connect explicitly to Angkor's baray.
4. [Assessment report](04-assessment-report.jpg): all four stations completed, with 12 completed activities, 11 correct first attempts and one retry. The original error remains visible despite eventual completion.

Use these four distinct stages for the assignment's development evidence, with captions explaining what changed and why. Do not present them as four views of an unchanged finished game.

The lesson blueprint is in [../lesson-blueprint.md](../lesson-blueprint.md). The screenshots remain source documentation; only the playable `dist/` directory is deployed to GitHub Pages.
